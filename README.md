# Bravely Pinned Tab

Actually pin your brave tabs.

## Installation

Clone the repo locally and load the unpacked extension from the root folder.

## Usage

Just enable the extension and you should be good to go

## How It Works

Whenever a pinned tab is closed, it is replaced by an "inactive" tab with the original tab's link. The favicon and title are saved as it was the moment the tab is closed. The "inactive" tab is unloaded and static page so it should be light on memory as well.

Whenever the "inactive" tab is brought to focus, it restores the original link as if cold booting the tab.
